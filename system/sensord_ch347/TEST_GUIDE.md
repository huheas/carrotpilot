# 传感器测试指南

## 快速开始

### 运行所有测试
```bash

source .venv/bin/activate
python3 system/sensord_ch347/test_sensor_all_scenarios.py
```

### 仅运行静态测试
```bash
python3 system/sensord_ch347/test_sensor_all_scenarios.py --static
```

### 仅运行动态测试
```bash
python3 system/sensord_ch347/test_sensor_all_scenarios.py --dynamic
```

```bash

```

## 测试场景说明

### 场景 1: 水平地面静止
- **目的**: 验证传感器基本功能和坐标系对齐
- **要求**: 车辆停在水平地面，保持静止
- **预期数据**:
  - X ≈ 0g（横向水平）
  - Y ≈ 0g（纵向水平）
  - Z ≈ 1g（垂直向上）
  - 总加速度 ≈ 1g

### 场景 2: 坡道车头朝上
- **目的**: 验证 Y 轴正向检测（车头朝上）
- **要求**: 车辆停在坡道上，车头朝上
- **预期数据**:
  - Y < 0（重力向后分解）
  - Z < 1g
  - 可以计算坡度角度

### 场景 3: 坡道车头朝下
- **目的**: 验证 Y 轴负向检测（车头朝下）
- **要求**: 车辆停在坡道上，车头朝下
- **预期数据**:
  - Y > 0（重力向前分解）
  - Z < 1g
  - 可以计算坡度角度

### 场景 4: 横向倾斜
- **目的**: 验证 X 轴检测（左右倾斜）
- **要求**: 车辆停在有横向倾斜的路面
- **预期数据**:
  - X 有明显值（≠ 0）
  - 正值 = 右倾，负值 = 左倾
  - Z < 1g

### 场景 5: 前进运动
- **目的**: 验证前进方向检测
- **要求**: 驾驶车辆前进（直线或转弯）
- **预期数据**:
  - 加速时 Y > 0
  - 匀速时 Y ≈ 0
  - 刹车时 Y < 0
  - 转弯时 X 有值

### 场景 6: 倒车运动
- **目的**: 验证倒车方向检测
- **要求**: 驾驶车辆倒车（直线或转弯）
- **预期数据**:
  - 加速时 Y < 0（与前进相反）
  - 匀速时 Y ≈ 0
  - 刹车时 Y > 0
  - 转弯时 X 有值

## 故障排查

### 传感器初始化失败
```bash
# 检查 I2C 设备是否存在
ls -l /dev/i2c-10

# 检查权限
sudo chmod 666 /dev/i2c-10

# 检查驱动是否加载
lsmod | grep ch347
```

### 数据采集失败过多
- 检查 I2C 连接是否稳定
- 检查传感器供电是否正常
- 尝试降低采集频率（修改 interval 参数）

### 测试数据异常
- 确认车辆状态符合测试场景要求
- 检查传感器安装方向是否正确
- 运行 `check_orientation.py` 验证坐标系

## 定期维护

建议每周运行一次完整测试，确保传感器工作正常：

```bash
# 创建 cron 任务（每周一次）
crontab -e

# 添加以下行（每周日 2:00 AM）
0 2 * * 0 cd /data/carrot2-v9-acc && source .venv/bin/activate && python3 system/sensord_ch347/test_sensor_all_scenarios.py --static > /tmp/sensor_test_$(date +\%Y\%m\%d).log 2>&1
```

## 注意事项

1. **静态测试**: 车辆必须完全静止
2. **动态测试**: 注意安全，建议在封闭场地测试
3. **数据采集**: 每次测试约需 5-10 秒
4. **坡道测试**: 确保车辆手刹已拉，安全第一
5. **动态测试**: 需要两人在场（驾驶员 + 操作员）
